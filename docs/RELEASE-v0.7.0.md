# v0.7.0 · 统一界面、代码清理与问题修复

本版本不新增 MCP 工具。Web 控制台改为与 AI Ops Platform 统一的设计；后端与前端逐行清理（不改变行为）；修复逐行审读时确认的问题。有一处表结构变化（新增一列，启动时自动添加，可回滚）。

## 界面

- 与 AI Ops Platform 共用一套设计系统：`web/ui-kit.css`（配色、字体、圆角、阴影、外壳与组件）与 `web/ui-kit.js`（主题切换、SVG 图标、窄屏抽屉），两个仓库中的同名文件逐字节相同；`web/app.css` 只保留本服务的页面组件。
- 毛玻璃侧栏与顶栏、胶囊按钮、带状态点的状态标签、分段控件（系统配置分类）、统一的表单、表格、弹窗、登录与初始化页。深浅色默认跟随系统，可手动切换；偏好的本地存储键由 `ssh-theme` 改为两边共用的 `ui-theme`，升级后首次打开跟随系统主题。
- 提示改为底部浮层，6 秒（错误 12 秒）自动消失，可点击关闭；侧栏底部显示版本（读取 `/healthz`）与登录用户。
- 交互修正：主机表显示跳板名称；公钥核验命令按扫描到的算法给出（此前 ECDSA 384/521 被指向 ed25519 文件）；扫描批次显示北京时间与中文状态；可信指纹预检的“目标已变化请重新扫描”提示此前被覆盖；“复制令牌”在 HTTP 内网下可用；批量启用的确认文案不再提“停用”；“编辑并启用资产”默认勾选启用；v0.6 新指标显示中文名；未登录打开首页不再显示“身份验证失效”；初始化成功提示不再随表单一起被隐藏。
- 静态文件改为一个白名单路由（新增 `ui-kit.*` 与 `favicon.svg`），资源地址带 `?v=0.7.0`。

## 问题修复

| 现象 | 修复 |
| --- | --- |
| 「操作审计」带关键词搜索返回 500 | SQL 参数个数改对 |
| 管理员在「编辑权限」去掉的扩展动作（如 nginx）每次重启被重新授予，并重复写审计 | 每个客户端只扩展一次，记录在 `mcp_clients.actions_extended`；v0.6.0 已扩展过的客户端按当时的审计记录标记；新建客户端在创建时标记，不再被补动作 |
| 凭据改成已存在的名称返回 500 | 与新增一致返回 409 |
| 删除主机组后，只改客户端诊断动作报 422「授权主机组不存在」 | 编辑时忽略已删除的组（组 id 不复用，不会扩大授权）；显式传入已删除的组仍返回 422 |
| 清理正忙时手动清理被审计为成功 | 审计记为 `failed` / `busy` |
| `ssh_triage` 等调用失败时审计缺少 `symptom` | 与成功时一致 |
| 工具描述：目录占用漏写 `/root`；进程排行写 25 个实际 24 个 | 描述改正 |
| `ssh_resolve_hosts` 一个 Host ID 格式错整批失败 | 该项返回 `invalid_argument`，其余照常 |
| `ssh_get_diagnostic_job` / `ssh_cancel_diagnostic_job` 失败时返回 “409: …” 字符串 | 返回带 `error_code` 的结构化结果 |

## 升级

先备份数据目录（至少 `ssh-mcp.sqlite3` 与密钥文件），然后在原部署目录执行：

```bash
cd /data/ssh-mcp-server
git fetch origin
git switch main
git pull --ff-only origin main
docker compose up -d --build --wait --wait-timeout 180
curl -fsS http://127.0.0.1:9099/healthz
```

`/healthz` 应返回 `0.7.0`（`.env` 的 `WEB_BIND_IP` 设成服务器地址时，curl 改用该地址）。

## 兼容性与回滚

- **表结构**：启动时给 `mcp_clients` 增加 `actions_extended TEXT NOT NULL DEFAULT ''`。回退到 v0.6.0 时旧代码按列名读取，多出的列不影响。
- **首次启动**：v0.6.0 已扩展过（有 `mcp_client_actions_extended` 审计记录）的客户端只打标记、不改动作；从未扩展过的老客户端按原规则扩展一次。v0.6.0 时被检查过但没补任何动作、且没有审计记录的客户端，最多会再被扩展一次（有审计）。
- **MCP 接口**：工具名、参数与成功结果不变；`ssh_resolve_hosts` 与任务查询 / 取消工具的失败结果改为结构化（只增不改）。AI Ops Platform 不调用这三个工具。
