初始化系统

首次启动时，使用一次性初始化凭据绑定飞书应用、登录域名及管理员 Open ID。成功保存后，初始化接口永久关闭；日常登录只能使用授权飞书账号。

在服务器执行 docker compose exec ssh-mcp cat /app/data/bootstrap.token 获取；不是长期登录凭据。

只填主机名或 IP 与可选端口，不包含 http:// 和路径。

多个管理员使用英文逗号隔开。必须包含你自己的飞书 Open ID；未授权用户无法登录。

返回登录

请先在飞书开发者后台将回调地址登记为：http(s)://你的服务器地址:9099/api/v1/auth/callback；并确保应用具有所需的身份认证权限。
